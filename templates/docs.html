API Documentation

Welcome to Agha AI Studio. Integrate our powerful Generative AI directly into your websites and applications using our secure REST API.

Authentication

All API requests must include your API Key in the Authorization header as a Bearer token. You can generate your API Key from the Developer Dashboard.

Authorization Header
Authorization: Bearer YOUR_API_KEY

Generate Text

Send a POST request to the following endpoint with a JSON body containing your prompt.

POST http://127.0.0.1:5000/api/v1/generate

cURL Example

Terminal 
curl -X POST http://127.0.0.1:5000/api/v1/generate \
-H "Content-Type: application/json" \
-H "Authorization: Bearer YOUR_API_KEY" \
-d '{"prompt": "Write a short slogan for a coffee shop."}'

Python Example

Python (requests) 
import requests

url = "http://127.0.0.1:5000/api/v1/generate"
headers = {
    "Authorization": "Bearer YOUR_API_KEY",
    "Content-Type": "application/json"
}
data = {"prompt": "Write a short slogan for a coffee shop."}

response = requests.post(url, json=data, headers=headers)
print(response.json())

JavaScript Example

JavaScript (fetch) 
const response = await fetch('http://127.0.0.1:5000/api/v1/generate', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer YOUR_API_KEY'
  },
  body: JSON.stringify({
    prompt: 'Write a short slogan for a coffee shop.'
  })
});

const data = await response.json();
console.log(data);
